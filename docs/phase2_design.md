# Phase 2: アセット制作(モデル・テクスチャ)

## ゴール
Phase3以降で実装に使うブロック/アイテム/ホログラムの見た目一式をBlockbenchで作成する。
Claudeがユーザーに作成手順を指導する形で進める。

## 作成対象
- パネルブロック(縁あり/縁なし)のモデル・テクスチャ
- カモフラージュ・メディアブロックのモデル・テクスチャ
- リモコンのアイテムアイコン・モデル
- ホログラム専用アイテムのアイコン
- ホログラム表示自体のプレースホルダー/エフェクト表現(GeckoLibのgeoモデルとして作成するか検討)

## 方針
- テクスチャ解像度は16x16で統一(要ユーザー確認)
- Blockbenchでの新規プロジェクト作成 → 「Minecraft Java Block/Item」モデル種別を選択
- 薄い板状パネルは厚み方向のみ縮小したキューブで作成(スライダーで可変にするため、複数厚みバリエーション不要。シェーダー/スケールで対応するか、基本モデル1つ+BlockStateスケールで対応するか要検討)
- 縁あり/縁なしはテクスチャ差分で表現(UV設計を分ける)
- GeckoLibを使う場合は「.geo.json」エクスポート、アニメーションは「.animation.json」で管理
- 出力先: resources/assets/mediapanelhologram/models, textures, geo, animations

## 指導手順(Claudeが次フェーズ開始時にガイドする内容)
1. Blockbenchインストール確認
2. プロジェクト新規作成(フォーマット選択)
3. パネルブロックのキューブ作成・UV展開・テクスチャ割り当て
4. エクスポートとファイル配置場所の指示
5. GeckoLibプラグイン導入(必要な場合)とアニメーション作成の基礎
