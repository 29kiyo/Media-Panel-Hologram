# Phase 4: メディアブロック実装

## ゴール
カモフラージュ機構とメディア再生機能(画像/動画/音楽/ブラウザ直接)を備えたブロックを実装する。

## タスク
- [ ] カモフラージュ用1スロットインベントリ実装、収納ブロックの見た目描画
- [ ] URL登録GUI実装
- [ ] モード切替UI(画像/動画/音楽/ブラウザ直接)
- [ ] MCEFの導入・埋め込みブラウザレンダリング実装(Phase1調査結果に基づく)
- [ ] ブロック単体でのブラウザ直接操作モード(リモコン不要、GUIから直接マウス操作)
- [ ] GIF再生対応
- [ ] 動画サイト対応実装: YouTube(IFrame Player API), Twitch(embed), ニコニコ動画(embed), bilibili(embed), その他汎用動画URL
- [ ] プレイリスト機能: 次へ/前へ/スキップ/シャッフル/キュー表示
- [ ] 音楽サイト対応: Spotify, YouTube Music, Apple Music(各サービスの埋め込み/API制約を要調査)

- [ ] サーバー管理者向けドメインホワイトリスト設定コマンド/コンフィグ
